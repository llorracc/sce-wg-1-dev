Place another paper's model in a borrowing-constraint scenario, or a family, by what its code solves: the laws it
actually integrates or the atoms it solves on, and the constraint it imposes. The continuous law its text states is not
enough.

**Why:** on 2026-11-01 the schemas put HAFiscal's members in a zero-infima version because the paper states untruncated
lognormals. The owner corrected it (13:51:57): HAFiscal never used that version. Its code solves on lognormals' atoms,
whose floors are positive, under a ≥ 0, which is the artificial scenario. The version was retired the same afternoon.

**How to apply:** before classifying a model, read or ask how its code builds the shocks and the constraint. Write the
members with the laws as solved (`Discrete` atoms, a truncated law), with a pointer to the code, and say where the text
and the code differ. Related: [[feedback_read-the-code-before-restating]], [[feedback_reaching-the-limit]].
