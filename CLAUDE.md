# Working in this fork

Read `schemas/records/MEMORY.md` before anything else: it is the schema project's memory, with its rulings, journal,
findings, deferred follow-ups and defects, kept in the repository so that every clone has it.

This repository is public and its history is permanent. Nothing private goes in it; the guard hook
(`git config core.hooksPath .githooks`) refuses the confidentiality marker and `*.private.md` files.
